# MassActivity01

Custom Discourse plugin for the MassActivity project.

## Locations

When Locations enables location controls for a topic, this plugin replaces the
address fields in the existing "Add a Location" window with one address search
field and a map. Search suggestions select an address and move the map marker;
clicking the map selects a point and looks up its address.

## Development

This repository contains the plugin code only.
Discourse core is maintained separately.
